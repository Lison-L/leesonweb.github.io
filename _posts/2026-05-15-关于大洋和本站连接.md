## 如何连接本站（换电脑后恢复）

如果你换了新电脑，或者想把网站文件迁移到另一台设备，按以下步骤操作：

### 第一步：克隆仓库到本地

```bash
git clone https://github.com/Lison-L/leesonweb.github.io.git
```

> 如果之前已经拷贝了文件到本地（比如从旧电脑拷贝了 `leesonweb` 文件夹），跳过这一步。

### 第二步：进入项目目录

```bash
cd leesonweb.github.io
```

或你存放 `leesonweb` 的路径：

```bash
cd ~/Downloads/leesonweb
```

### 第三步：配置 Git 用户信息

```bash
git config user.name "Leeson"
git config user.email "lisontoto@gmail.com"
```

### 第四步：确保 Jekyll 环境可用

本站基于 Jekyll + GitHub Pages 构建。确保本机安装了 Ruby 和 Bundler：

```bash
# 检查 Ruby
ruby -v

# 安装依赖
bundle install
```

### 第五步：本地预览（可选）

```bash
bundle exec jekyll serve
```

浏览器打开 `http://localhost:4000` 即可预览。

### 第六步：撰写文章

在 `_posts/` 目录下新建 Markdown 文件，命名格式：

```
YYYY-MM-DD-文章标题.md
```

文件头部需要包含 Front Matter：

```yaml
---
layout: post
title: 你的文章标题
date: YYYY-MM-DD HH:MM +0800
tags: [标签1, 标签2]
toc:  true
---
```

### 第七步：推送到 GitHub

```bash
git add .
git commit -m "新文章：文章标题"
git push origin master
```

推送后，GitHub Pages 会自动构建部署，几分钟后 `loloio.com` 就会更新。

## 注意事项

1. **Token 安全**：Git 远程地址中可能嵌入了 Personal Access Token，注意不要泄露。建议改用 SSH 方式：
   ```bash
   git remote set-url origin git@github.com:Lison-L/leesonweb.github.io.git
   ```

2. **国内网络**：GitHub 在国内访问可能较慢，可以考虑配置代理或使用镜像。

3. **随时找我**：后续文章更新、站点维护，直接告诉我就好 🌊
